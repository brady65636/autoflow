# 大众售后 Agent 知识框架：症状 → 可能原因 → 服务

> 版本：v0.1（知识建模草案）
> 用途：客户咨询分流、追问和服务项目推荐；不是远程最终诊断。

## 1. Agent 的基本判断链

```text
客户症状
→ 确认品牌/车型/年款/动力/里程/VIN（至少车型年款和燃油/混动/纯电）
→ 确认故障灯颜色、是否闪烁、文字提示
→ 确认发生条件：冷车/热车/加速/制动/转弯/充电/换挡
→ 先做安全分级
→ 给出 2～5 个可能方向，而不是单一结论
→ 推荐检查项目和预约类型
→ 到店使用诊断仪、目视检查和实测数据确认
```

## 2. 安全分级

### P0：立即停车/熄火/联系救援

- 机油压力警告灯闪烁，或伴随发动机异响；
- 冷却液温度过高、冷却液警告持续出现、蒸汽或明显泄漏；
- 制动系统红色警告灯，制动踏板异常、制动力下降或制动液不足；
- 转向系统红色警告、方向盘明显变重或无法稳定控制；
- 高压电池/电驱系统冒烟、异味、碰撞后、进水后或出现高压系统严重警告；
- 轮胎破损、快速漏气、车辆明显跑偏或异常振动。

### P1：低速谨慎前往 4S 店/必要时救援

- ABS、ESP、电子驻车制动故障；
- EPC/发动机控制故障并伴随动力明显受限、抖动或无法加速；
- 变速箱故障灯持续亮，换挡冲击、无法挂挡或进入保护模式；
- 发动机故障灯闪烁；
- 充电系统或高压系统故障，车辆无法正常进入行驶就绪状态。

### P2：尽快预约检查

- 黄色发动机故障灯常亮且车辆运行基本正常；
- 胎压报警但轮胎无明显损伤；
- 蓄电池/发电机警告但车辆仍可行驶；
- 空调、车窗、灯光、辅助驾驶功能异常；
- 异响、轻微抖动、轻微渗漏且没有安全系统报警。

### P3：保养/功能咨询

- 保养周期到期；
- 玻璃水、燃油不足；
- 车机、钥匙、座椅、灯光等使用问题；
- 轻微异味但没有烟雾、温度异常或液体泄漏。

## 3. 典型症状知识卡

### 3.1 发动机故障灯

**可能方向**

- 排放控制系统、氧传感器、三元催化器；
- 点火系统：火花塞、点火线圈、失火；
- 进气/增压系统：进气泄漏、节气门、增压压力异常；
- 燃油系统：燃油压力、喷油器、燃油品质；
- EVAP 蒸发排放系统或油箱盖密封；
- 低电压、传感器或控制单元通信异常。

**必须追问**

- 常亮还是闪烁？是否伴随 EPC？
- 发动机是否抖动、动力下降、排气异味？
- 冷车还是热车发生？加速时是否更明显？
- 最近是否加油、洗车、维修或更换电瓶？
- 是否有 OBD 故障码？不能仅凭故障码直接确定更换部件。

**推荐服务**

- 发动机/排放系统诊断；
- 读取全车故障码和冻结帧；
- 点火、进气、燃油、排放系统检查；
- 根据实测结果安排维修，不建议 Agent 直接承诺更换某个零件。

**安全规则**

- 常亮且无明显异常：尽快预约检查，避免长时间高负荷驾驶；
- 闪烁或伴随明显抖动/动力下降：按高风险处理，减少驾驶，必要时救援。

### 3.2 EPC/电子节气门相关报警

**可能方向**

- 电子节气门控制系统；
- 加速踏板位置传感器；
- 发动机控制单元、线束或电源电压；
- 点火失火、增压或进气控制异常。

**推荐服务**

- 发动机控制系统诊断；
- 节气门、加速踏板、线束和供电检查；
- 检查是否进入跛行/动力限制模式。

**安全规则**

- 动力严重受限、加速踏板无响应或车辆抖动：不要继续正常行驶，转人工/救援。

### 3.3 机油压力/机油警告

**可能方向**

- 机油液位不足或机油泄漏；
- 机油压力异常、机油泵或润滑系统；
- 机油压力传感器或线路；
- 使用了不符合要求的机油。

**必须追问**

- 红色还是黄色？常亮还是闪烁？
- 是否有发动机异响、烧焦味或明显漏油？
- 最近是否保养、加过机油或发生碰撞？

**推荐服务**

- 安全停车、关闭发动机；
- 按对应车型手册检查液位；
- 机油压力实测、泄漏检查和润滑系统诊断。

**安全规则**

- 警告持续或闪烁：不得让发动机继续运转，不能只建议“补机油后继续开”。

### 3.4 冷却液温度/冷却系统

**可能方向**

- 冷却液不足或泄漏；
- 散热器风扇、节温器、水泵；
- 温度传感器或线路；
- 冷却系统内部压力异常。

**推荐服务**

- 立即安全停车并关闭发动机；
- 检查温度、冷却液液位、泄漏和风扇；
- 冷却系统压力测试和冷却液规范检查。

**安全规则**

- 高温、蒸汽、持续报警或再次升温：禁止继续行驶。

### 3.5 制动系统/ABS/ESP/电子驻车

**可能方向**

- 制动液不足或泄漏；
- 刹车片/刹车盘磨损；
- ABS 轮速传感器、液压单元或控制单元；
- 电子驻车执行器、开关、线路；
- 低电压导致的系统故障；
- ESP/ASR 被关闭或传感器校准异常。

**必须追问**

- 红色还是黄色？哪些灯同时出现？
- 制动踏板是否变软、变硬或行程变长？
- 是否出现跑偏、异响、ABS 介入异常？

**推荐服务**

- 制动系统安全检查；
- 制动液液位和泄漏检查；
- 轮速传感器、ABS/ESP 故障码和数据流检查；
- 电子驻车系统诊断。

**安全规则**

- 制动性能异常、红色制动警告、ABS 与制动警告同时出现：优先停车/救援。

### 3.6 胎压报警

**可能方向**

- 轮胎漏气、扎钉或胎壁损伤；
- 四轮胎压不一致；
- 胎压监测传感器/系统故障；
- 轮胎更换或换位后尚未重新设置；
- 外部无线电干扰。

**推荐服务**

- 安全停车，检查四轮外观和实际胎压；
- 检查轮胎损伤、轮毂和气门嘴；
- 按车型要求重新设置/校准胎压监测；
- 持续报警时进行 TPMS 诊断。

**安全规则**

- 快速漏气、胎壁损伤或明显异常：不得继续行驶。

### 3.7 蓄电池/发电机/电气系统

**可能方向**

- 12V 蓄电池老化或亏电；
- 发电机不充电；
- 皮带、供电线路或搭铁异常；
- 低电压导致多个控制单元同时报码；
- 车身网络通信异常。

**推荐服务**

- 12V 电池健康度和静态电压检查；
- 充电电压、发电机和供电线路检查；
- 全车控制单元扫描，区分真实故障与低电压连锁报码。

**安全规则**

- 行驶中充电警告出现时，关闭不必要的电器并尽快到店；若伴随动力、转向或制动异常，立即停车。

### 3.8 DSG/变速箱换挡异常

**可能方向**

- 离合器磨损或温度过高；
- 机电单元、液压控制或传感器；
- 双质量飞轮、传动半轴或发动机/变速箱支架；
- 低电压、软件或通信异常；
- 变速箱油液/维护状态不符合要求（具体以变速箱型号和车型要求为准）。

**必须追问**

- 是起步抖动、升挡冲击、降挡冲击还是无法挂挡？
- 冷车/热车是否不同？倒车是否正常？
- 是否出现变速箱故障灯、挡位闪烁或保护模式？
- 最近是否涉水、维修、拖车或更换电瓶？

**推荐服务**

- 变速箱控制单元故障码与数据流；
- 离合器、机电单元、油液/温度和基础设定检查；
- 试车复现和发动机/变速箱协同检查。

**安全规则**

- 无法挂挡、严重冲击、持续报警或车辆失去驱动力：停止驾驶并联系救援。

### 3.9 空调不制冷/制热异常

**可能方向**

- 制冷剂不足或泄漏；
- 压缩机、冷凝器、蒸发器或膨胀阀；
- 鼓风机、风门执行器或滤芯；
- 发动机冷却系统或电动车热管理系统；
- 高压空调系统、热泵或电加热器。

**推荐服务**

- 空调压力、温度、泄漏和执行器检查；
- 检查空调滤芯和风量；
- ID/MEB 车型按高压热管理流程由受训人员检查。

### 3.10 ID 纯电/插混车辆异常

**可能方向**

- 高压电池、驱动电机、电控或热管理系统；
- 充电枪、充电桩、车载充电机；
- 12V 低压电池；
- 高压互锁、绝缘监控或碰撞保护；
- 软件/通信或温度限制。

**必须追问**

- 车辆能否进入行驶就绪状态？
- 是无法充电、充电中断、续航骤降还是动力受限？
- 是否发生碰撞、涉水、底盘托底、异味、冒烟或发热？
- 仪表显示的完整文字是什么？

**安全规则**

- 碰撞、涉水、冒烟、异味、高压警告或电池异常发热：不得自行拆修或继续充电，立即隔离并联系救援/授权维修人员。

## 4. Agent 不应直接做出的结论

- 不应仅凭“发动机灯亮”判断为某个具体零件损坏；
- 不应仅凭一个 OBD 码建议直接更换零件；
- 不应将某一发动机代号的经验套用于所有年款和车型；
- 不应把 SSP 原理资料当成维修操作规范；
- 不应在未确认车型、年款、动力和故障灯状态时给出“可以继续开”的结论；
- 不应指导客户拆解制动、高压电池、燃油和安全气囊系统。

## 6. 资料来源和使用边界

- 上汽大众官方仪表灯页面：提供部分“可能原因”和“解决措施”；
- 大众/上汽大众官方用户手册：按车型、年款、动力版本确认车主可执行操作；
- EA211、EA888、ESP、热泵、电气系统 SSP：用于系统结构和工作原理学习；
- 交通运输部维修技术信息公开目录：用于定义维修技术资料应覆盖的系统范围；
- 具体维修方法、扭矩、油液、标定、软件版本、故障码诊断树必须引用对应车型的当前厂家售后技术资料。
